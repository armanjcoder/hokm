## 🎯 این پروژه چیست؟

**Hokm Club** یک پیاده‌سازی کامل از بازی ورق **حکم** است که مستقیماً داخل تلگرام
اجرا می‌شود — بدون نصب اپ، بدون ثبت‌نام.

پروژه از سه بخش تشکیل شده:

| بخش | نقش |
|---|---|
| 🃏 **موتور بازی** | تمام قوانین حکم به‌صورت TypeScript خالص، بدون هیچ وابستگی به شبکه یا UI |
| ⚡ **بک‌اند** | مدیریت میزها، بلادرنگ با Socket.IO، ربات تلگرام، پایداری روی SQLite |
| 📱 **مینی‌اپ** | رابط React موبایل‌محور و RTL که داخل تلگرام باز می‌شود |

## ✨ ویژگی‌ها

**بازی**
- سه حالت **۴ نفره تیمی**، **۳ نفره انفرادی** و **۲ نفره دوئل** با قوانین اختصاصی هرکدام
- امتیازدهی کامل: عادی، **کوت**، **حاکم‌کوت** و **بام**
- قوانین اختیاری **ده‌لو کم** و **بام** (هر دو پیش‌فرض روشن، مثل میز واقعی)
- امتیاز هدف قابل انتخاب: ۳، ۵، ۷ یا ۱۱
- راهنمای قوانین درون‌برنامه‌ای، مخصوص هر حالت

**میز و بازیکنان**
- لابی با سیستم **آماده‌باش** — از ۱ تا ۴ بازیکن انسانی، بقیه ربات
- ربات‌ها با سه سطح **آسان / متوسط / سخت**، قابل تغییر در لابی، حتی ترکیبی سر یک میز
- میزبان واقعی با انتقال خودکار در صورت خروج
- **اتصال مجدد خودکار** — قطعی اینترنت یا ری‌استارت سرور بازی را خراب نمی‌کند
- ادامه‌ی میز قبلی با یک کلیک

**فنی**
- احراز هویت امن با اعتبارسنجی امضای `initData` تلگرام
- محدودسازی نرخ درخواست، پاک‌سازی ورودی، نوشتن اتمی دیتابیس، خاموشی تمیز
- پاک‌سازی خودکار میزهای رهاشده
- تمام پیام‌های خطا فارسی، با کد ماشین‌خوان جداگانه

## 🎮 حالت‌های بازی

| حالت | بازیکن | تیم‌بندی | کارت هر نفر | نحوه‌ی پخش | نکته‌ی ویژه |
|---|:---:|---|:---:|---|---|
| **۴ نفره** `classic4` | ۴ | دو تیم دونفره (۰و۲ مقابل ۱و۳) | ۱۳ | ۵ + ۴ + ۴ | حالت کلاسیک حکم |
| **۳ نفره** `solo3` | ۳ | هرکس برای خودش | ۱۷ | ۵ + ۴ + ۴ + ۴ | یک کارت `۲` حذف می‌شود و هرگز خال حکم نمی‌شود |
| **۲ نفره** `duel2` | ۲ | هرکس برای خودش | ۱۳ | ۵ کارت، سپس دور انداختن و برداشتن | مکانیک «سوزاندن و برداشتن» |

<details>
<summary><b>جزئیات حالت دو نفره</b></summary>

۱. حاکم با کشیدن آس مشخص می‌شود.
۲. به هر نفر ۵ کارت داده می‌شود.
۳. حاکم خال حکم را انتخاب می‌کند.
۴. هر دو بازیکن **۲ کارت کم‌ارزش** را دور می‌اندازند.
۵. یک‌درمیان از پاکت برمی‌دارند؛ هر بار کارت رو را می‌بینند و انتخاب می‌کنند:
   - **نگه داشتن** ⇒ کارت بعدی نادیده سوزانده می‌شود
   - **سوزاندن** ⇒ باید کارت بعدی را نادیده بردارند
۶. تا تمام‌شدن پاکت ادامه دارد؛ هرکس با ۱۳ کارت تمام می‌کند.
۷. هرکس زودتر ۷ دست ببرد، برنده است.

</details>

## 📊 قوانین و امتیازدهی

| نتیجه | امتیاز | شرط |
|---|:---:|---|
| برد عادی | **۱** | رسیدن به ۷ دست |
| **کوت** | **۲** | همه‌ی حریفان صفر دست بگیرند |
| **حاکم‌کوت** | **۳** | تیم حاکم کاملاً شات‌اوت شود |
| **بام** | **۳** | بردن تمام دست‌ها — **کل مسابقه بلافاصله تمام می‌شود** |

### قوانین اختیاری

> هر دو **پیش‌فرض روشن** هستند، چون در بازی واقعی هم معمولاً همین‌طور است.

- **ده‌لو کم** — اگر ۵ کارت اول حاکم هیچ آس، شاه، بی‌بی یا سربازی نداشت،
  می‌تواند درخواست پخش مجدد کند. سرور شرط را بررسی می‌کند و حداکثر ۲ بار پشت‌سرهم مجاز است.
- **بام** — بازی بعد از ۷ دست هم ادامه پیدا می‌کند تا معلوم شود آیا یک طرف
  همه‌ی دست‌ها را می‌برد یا نه.

## 🤖 ربات‌های حریف

سه سطح که **واقعاً** با هم فرق دارند — نه فقط یک عدد متفاوت.

| سطح | رفتار |
|---|---|
| 🟢 **آسان** | منطق درست بازی را می‌فهمد ولی حدود ۲۵٪ مواقع اشتباه می‌کند |
| 🟡 **متوسط** | اشتباه نمی‌کند، ارزان‌ترین برد را انتخاب می‌کند، هرگز روی یار خودش نمی‌زند، بلندترین خال کناری را لید می‌کند |
| 🔴 **سخت** | کارت‌ها را می‌شمارد، برنده‌های قطعی را نقد می‌کند، حکم حریف را می‌کشد، خال خالی می‌کند و به خال‌هایی که می‌داند حریف ندارد لید نمی‌کند |

**نتایج واقعی** (بیش از ۱۰۰۰ مسابقه‌ی seed‌دار با جابه‌جایی صندلی برای حذف سوگیری):

```
متوسط  در برابر  آسان   →  ۷۴٪
سخت   در برابر  آسان   →  ۷۷٪
سخت   در برابر  متوسط  →  ۵۵.۵٪
```

> **صادقانه:** فاصله‌ی «سخت» تا «متوسط» کم است. بیشترکردن آن نیاز به جست‌وجوی
> درختی دارد که برای یک Mini App تلگرام سنگین است. این محدودیت آگاهانه پذیرفته شده.

## 🚀 شروع سریع

**پیش‌نیاز:** Node.js نسخه ۲۰ یا بالاتر

```bash
git clone https://github.com/armanjcoder/hokm.git
cd hokm
npm install
cp apps/api/.env.example apps/api/.env
npm run dev
```

| سرویس | آدرس |
|---|---|
| مینی‌اپ | http://localhost:5173 |
| API | http://localhost:4000 |
| سلامت سرویس | http://localhost:4000/health |

برای تست در مرورگر بدون تلگرام، در `.env` مقدار `ALLOW_UNVERIFIED_TELEGRAM=true`
را بگذارید تا همه به‌عنوان «مهمان» وارد شوند.

> ⚠️ این گزینه فقط برای توسعه است. در استفاده‌ی واقعی حتماً `false` بماند.

### اسکریپت‌ها

```bash
npm run build      # بیلد همه‌ی پکیج‌ها
npm run test       # اجرای کل تست‌ها
npm run typecheck  # بررسی تایپ‌ها (شامل فایل‌های تست)
npm run dev        # اجرای همزمان API و مینی‌اپ
```

## ⚙️ پیکربندی

تمام تنظیمات در `apps/api/.env` است. نمونه‌ی کامل در `apps/api/.env.example` موجود است.

```env
PORT=4000
DB_PATH=./data/hokm.sqlite
SERVE_WEB_DIST=true

# هر سه، همان آدرس عمومی برنامه
WEB_APP_URL=https://hokm.example.com
PUBLIC_API_URL=https://hokm.example.com
CORS_ORIGIN=https://hokm.example.com

TELEGRAM_BOT_TOKEN=
ALLOW_UNVERIFIED_TELEGRAM=false

# اختیاری: پروکسی فقط برای ترافیک Bot API
TELEGRAM_PROXY_URL=

# چرخه‌ی عمر میزها (ساعت)
ROOM_LOBBY_TTL_HOURS=6
ROOM_PLAYING_TTL_HOURS=12
ROOM_FINISHED_TTL_HOURS=24
ROOM_CLEANUP_INTERVAL_HOURS=1

# محافظت در برابر سوءاستفاده
RATE_LIMIT_CREATE_PER_MIN=6
RATE_LIMIT_ACTIONS_PER_MIN=60
MAX_ROOMS=500
```

<details>
<summary><b>🔌 پروکسی مخصوص تلگرام — وقتی VPN مشکل‌ساز است</b></summary>

روی شبکه‌های فیلترشده دو نیاز با هم تضاد پیدا می‌کنند:

- بدون VPN، آدرس `api.telegram.org` در دسترس نیست و ربات بالا نمی‌آید.
- با VPN سیستمی، تونل Cloudflare قطع می‌شود.

راه حل: VPN سیستمی را روشن نکنید و به‌جایش **فقط** ترافیک Bot API را پروکسی کنید:

```env
TELEGRAM_PROXY_URL=socks5://127.0.0.1:10808
```

کلاینت VPN باید باز باشد ولی حالت **TUN / System Proxy / Global آن خاموش** بماند.

پورت‌های رایج: v2rayN → `10808` · Nekoray → `2080` · Hiddify → `12334`
پروکسی HTTP هم پشتیبانی می‌شود: `http://127.0.0.1:8080`

هنگام اجرا این خط چاپ می‌شود (رمز عبور هرگز نمایش داده نمی‌شود):

```
Telegram bot network: socks5://127.0.0.1:10808.
```

</details>

## 🌐 انتشار روی اینترنت

تلگرام برای Mini App حتماً **HTTPS** می‌خواهد. دو مسیر وجود دارد:

### الف) اجرا روی لپ‌تاپ + تونل Cloudflare

مناسب برای توسعه و بازی با دوستان. بازی تا وقتی لپ‌تاپ روشن است در دسترس است.

```yaml
# ~/.cloudflared/config.yml
tunnel: <TUNNEL-ID>
credentials-file: <path>/<TUNNEL-ID>.json
protocol: http2          # اگر پورت ۷۸۴۴ UDP بسته است، ضروری است
ingress:
  - hostname: hokm.example.com
    service: http://localhost:4000
  - service: http_status:404
```

```bash
npm run build
npm run start -w @hokm/api    # ترمینال ۱
cloudflared tunnel run hokm   # ترمینال ۲
```

راهنمای کامل: [`docs/LOCAL_LAPTOP_SETUP.md`](docs/LOCAL_LAPTOP_SETUP.md)

### ب) اجرا روی VPS

مناسب برای دسترسی همیشگی. Node 20 + nginx + pm2 + certbot.

> ⚠️ اگر از Cloudflare استفاده می‌کنید، برای رکورد DNS حالت **پروکسی را خاموش**
> کنید، وگرنه WebSocket می‌شکند. در nginx حتماً هدرهای
> `Upgrade` و `Connection: upgrade` و `proxy_read_timeout 86400` را بگذارید.

### در نهایت، در BotFather

```
/setdomain   →  hokm.example.com
/newapp      →  آدرس Mini App را همان دامنه بگذارید
```

```text
hokm/
├── apps/
│   ├── api/                    بک‌اند: Express + Socket.IO + grammY

│   │       ├── config.ts       تنها جایی که env خوانده می‌شود
│   │       ├── storage.ts      پایداری SQLite با نوشتن اتمی
│   │       ├── telegram-auth.ts اعتبارسنجی امضای initData
│   │       ├── game/           ربات‌ها، هوش مصنوعی، سرویس میز، viewها
│   │       ├── http/           اپ، میان‌افزارها، مسیرها
│   │       ├── realtime/       broadcast و هندلرهای سوکت
│   │       ├── telegram/       ربات و پروکسی
│   │       └── jobs/           پاک‌سازی خودکار
│   │
│   └── web/                    مینی‌اپ: React + Vite، RTL و موبایل‌محور
│       └── src/
│           ├── api/            کلاینت HTTP، سوکت، ذخیره‌سازی، SDK تلگرام
│           ├── hooks/          session، اتصال میز، اکشن‌های بازی و لابی
│           ├── components/     ۱۴ کامپوننت رابط کاربری
│           └── styles/         CSS تفکیک‌شده بر اساس ناحیه
│
└── packages/
    └── game-engine/            موتور قوانین، کاملاً مستقل از شبکه و UI
        └── src/                cards, modes, rules, duel, redeal,
                                trick, hand-flow, legal-moves, public-view
```

**اصول طراحی**

- موتور بازی **هیچ** وابستگی به تلگرام، دیتابیس یا UI ندارد و کاملاً قابل تست است.
- هر فایل حدود **۲۵۰ خط** یا کمتر است.
- `config.ts` تنها نقطه‌ی خواندن متغیرهای محیطی است.
- هر بازیکن فقط **دست خودش** را دریافت می‌کند؛ `toPublicView` بقیه را حذف می‌کند.

جزئیات بیشتر: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)

## 🔌 API

### HTTP

| متد | مسیر | توضیح |
|---|---|---|
| `GET` | `/health` | بررسی سلامت سرویس |
| `GET` | `/rooms/:roomId` | دریافت وضعیت میز |
| `POST` | `/rooms` | ساخت میز جدید |
| `POST` | `/rooms/:roomId/join` | پیوستن به میز |
| `POST` | `/rooms/:roomId/settings` | تغییر حالت و امتیاز هدف (فقط میزبان) |
| `POST` | `/rooms/:roomId/add-bot` | افزودن یک ربات |
| `POST` | `/rooms/:roomId/bot-difficulty` | تغییر سطح یک ربات |
| `POST` | `/rooms/:roomId/remove-bot` | حذف ربات |
| `POST` | `/rooms/:roomId/ready` | اعلام آمادگی |
| `POST` | `/rooms/:roomId/leave` | ترک میز |

### Socket.IO

**کلاینت ← سرور**

```
room:join            game:choose_trump    game:play_card
game:next_hand       game:redeal          game:discard
game:draw            game:resolve_draw
```

**سرور ← کلاینت**

```
room:update          snapshot اختصاصی همان بازیکن
```

## 🧪 تست و کیفیت

```
موتور بازی    ۱۰۰ تست
بک‌اند         ۲۱۷ تست
مینی‌اپ        ۱۰۶ تست
─────────────────────
مجموع         ۴۲۳ تست
```

تست‌ها فقط unit نیستند:

- **تست‌های e2e واقعی** با سرور spawn‌شده — برای بررسی ری‌استارت و اتصال مجدد
- **هارنس ۷۲۰ مسابقه‌ای** برای بررسی invariantهای موتور (باگ هنگ سه‌نفره را پیدا کرد)
- **سنجش قدرت ربات‌ها** روی صدها مسابقه‌ی seed‌دار با جابه‌جایی صندلی
- **ممیزی امنیتی** با ۳۰ بررسی شامل fuzzing
- تست‌های کامپوننت و هوک با `@testing-library/react`

```bash
npm run test       # همه
npm run typecheck  # تایپ‌ها، شامل خود فایل‌های تست
```

## 🔒 امنیت

| موضوع | راهکار |
|---|---|
| **جعل هویت** | فقط `initData` امضاشده‌ی تلگرام معتبر است؛ `telegramId` ارسالی کلاینت نادیده گرفته می‌شود |
| **دزدیدن نشست** | هر بازیکن یک `playerToken` مخفی دارد که با `timingSafeEqual` بررسی می‌شود |
| **تقلب در بازی** | هر بازیکن فقط دست خودش را دریافت می‌کند؛ منطق کامل سمت سرور اجرا می‌شود |
| **اسپم** | محدودسازی نرخ با پنجره‌ی لغزان + سقف تعداد میزها |
| **ورودی مخرب** | پاک‌سازی نام: حذف control character، bidi override و zero-width |
| **خرابی داده** | نوشتن اتمی با temp+rename و بازیابی خودکار دیتابیس خراب |

> 🔑 توکن ربات را هرگز commit نکنید. فایل `.env` در `.gitignore` است.
> اگر توکنی جایی لو رفت، فوراً در BotFather دستور `/revoke` را بزنید.

## 🩺 عیب‌یابی

<details>
<summary><b>مینی‌اپ باز می‌شود ولی صفحه سفید/خالی می‌ماند</b></summary>

اسکریپت SDK تلگرام از `telegram.org` گرفته می‌شود که روی بعضی شبکه‌ها مسدود است
و درخواست به‌جای رد شدن سریع معلق می‌ماند.

این مشکل رفع شده: SDK حالا به‌صورت async با مهلت ۲.۵ ثانیه بارگذاری می‌شود و اگر
نیامد، برنامه به‌هرحال رندر می‌شود. اگر باز هم دیدید، مینی‌اپ را Reload کنید تا
کش تلگرام پاک شود.

</details>

<details>
<summary><b>ربات بالا نمی‌آید: <code>connect ETIMEDOUT 10.10.34.36:443</code></b></summary>

این آی‌پی صفحه‌ی فیلترینگ است، یعنی `api.telegram.org` در دسترس نیست.
از `TELEGRAM_PROXY_URL` استفاده کنید (بخش پیکربندی را ببینید).

توجه: خود بازی سالم بالا می‌آید و فقط ربات غیرفعال می‌شود — این رفتار عمدی است.

</details>

<details>
<summary><b>تونل Cloudflare وصل نمی‌شود</b></summary>

اگر در پیش‌بررسی، پورت ۷۸۴۴ روی UDP یا TCP خطا داد، ISP آن را بسته است.
در `config.yml` مقدار `protocol: http2` را بگذارید تا از QUIC استفاده نکند.

</details>

<details>
<summary><b>خطای ERESOLVE هنگام نصب</b></summary>

**هرگز `npm audit fix --force` نزنید.** یک بار نسخه‌ی vite را به ۸ برد و با
`@vitejs/plugin-react` ناسازگار شد.

راه بازگشت:

```bash
git restore .
rm -rf node_modules apps/*/node_modules packages/*/node_modules
npm install
```

</details>

<details>
<summary><b>WebSocket پشت nginx یا Cloudflare کار نمی‌کند</b></summary>

- در Cloudflare حالت **پروکسی (ابر نارنجی) را خاموش** کنید، یا از تونل استفاده کنید.
- در nginx هدرهای `Upgrade` و `Connection: upgrade` و `proxy_read_timeout 86400` لازم است.
- در برنامه `app.set('trust proxy', true)` از قبل تنظیم شده است.

</details>
